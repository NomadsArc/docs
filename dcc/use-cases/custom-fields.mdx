How to display **Custom Fields** for the customers on the Checkout using the **Custom ->** **Content -> Form** option.

## Guide

<Steps>
  <Step title="**Create a new customization**">
    Create a new [customization](https://admin.shopify.com/apps/dynamic-checkout-customizer/customizations).

    ![Image](/images/image-38.png "Image")
  </Step>
  <Step title="**Choose the Form type**">
    Select **Form** from the available content types to display custom form elements during checkout.

    ![Custom Content Card Form Focus](/images/custom_content_card_form_focus.png "Custom Content Card Form Focus")
  </Step>
  <Step title="**Configure display conditions**">
    Add one or more **conditions** to control when the form is displayed during checkout.

    ![Form Conditional Experience Focus](/images/form_conditional_experience_focus.png "Form Conditional Experience Focus")
  </Step>
  <Step title="**Configure form settings**">
    Configure the **Form Settings**, including:

    - **Element Type** (Checkbox or Text Field)
    - **Label** displayed to customers
    - **Key** used to save the value in the Shopify order

    ![Form Heading Settings Add Element Focus](/images/form_heading_settings_add_element_focus.png "Form Heading Settings Add Element Focus")

    ![Image (2)](/images/image-\(2\)-1.png "Image (2)")

    ![Form Heading Settings Focus](/images/form_heading_settings_focus-1.png "Form Heading Settings Focus")
  </Step>
  <Step title="**Customize the display**">
    Configure the **Display Settings** to control how the custom form fields appear during checkout.

    ![Form Display Settings Focus](/images/form_display_settings_focus.png "Form Display Settings Focus")
  </Step>
  <Step title="**Activate the customization**">
    Change the **Status** to **Active** using toggle button to enable the customization.

    ![Form Toolbar Focus](/images/form_toolbar_focus.png "Form Toolbar Focus")
  </Step>
  <Step title="**Set the priority**">
    Configure the **Priority** (0–100) to determine the execution order when multiple customizations are eligible.

    ![Form Priority Focus](/images/form_priority_focus.png "Form Priority Focus")
  </Step>
  <Step title="**Copy the Placement ID**">
    Copy the generated **Placement ID** from clipboard icon. You'll use this in the Shopify Checkout Editor.

    ![Form Copy Placement Id Focus](/images/form_copy_placement_id_focus.png "Form Copy Placement Id Focus")
  </Step>
  <Step title="**Save the customization**">
    Click **Save** to store your configuration.

    ![Form Unsaved Changes Focus](/images/form_unsaved_changes_focus.png "Form Unsaved Changes Focus")
  </Step>
  <Step title="**Open the Checkout Editor**">
    Go to your Shopify [**Settings**](https://admin.shopify.com/settings) → Checkout, select your checkout profile, and click **Edit**.

    ![](/images/screenshot_08.png)
  </Step>
  <Step title="**Add the app block**">
    In the [Checkout Editor](https://admin.shopify.com/settings/checkout/editor), click **Add app block**.

    ![Screenshot 2026 10 08 At 16 07 56](/images/Screenshot-2026-10-08-at-16.07.56.png "Screenshot 2026 10 08 At 16 07 56")

    <Note>
      Make sure the app block is placed in the same checkout placement you selected in Dynamic Checkout Customizer.
    </Note>
  </Step>
  <Step title="**Configure the app block**">
    Select the **Checkout – Form Elements** app block, and paste the copied **Placement ID**.

    ![Image (4)](/images/image-\(4\)-1.png "Image (4)")
  </Step>
  <Step title="**Publish your changes**">
    Click **Save** in the Checkout Editor to publish the customization.

    ![Form Elements Save Disabled](/images/form_elements_save_disabled-2.png "Form Elements Save Disabled")
  </Step>
</Steps>

<Note>
  **Why does it matter?**

  [Sunco](https://www.sunco.com/) uses the **Notifications → Form** customization to collect additional customer information during checkout, helping improve its brand reputation and customer experience.
</Note>
